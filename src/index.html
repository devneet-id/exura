01 · The series

One idea, three layers

Each package works alone. Together they cover a whole small web app — page, behaviour and API — with the same mindset: say what you want in plain words.

css

exuracss

Styling through attributes: button, card, ring, flex, size. Dark mode by reversal, responsive by prefix.

  • md:size="w:1/2"
  • <body dark> anywhere
  • colors from exura.json
Repository
js

exurajs

Reactive modules in one small file: state, effect, {{key}} templates inside your own tags, a router and a DOM helper.

  • <exura-counter> = module
  • placeholders in attributes
  • ~5 KB minified
Repository
php

exuraphp

JSON APIs in a single PHP file: modules per route, wildcards, a trace block for debugging and a clean 404.

  • Exura::module('GET', 'user/*')
  • errors become JSON
  • no framework to learn
Repository

03 · Principles

Small on purpose

No build step

One <link>, one <script>, one require.

Readable markup

Attributes say what an element is, not a list of classes.

Dark by reversal

[dark] flips the neutral pairs — on the page or one panel.

Open source

MIT, maintained by DEVNEET. Issues and PRs welcome.

Start with one line.
Add the rest when you need it.

Pick the piece you need — each one works on its own. Version 1.1.0, served by jsDelivr from the release tag.

css
exuracss
the look
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/devneet-id/exuracss@1.1.0/dist/exura.min.css">

<!-- icons, optional -->
<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/gh/devneet-id/exuracss@1.1.0/dist/exura-clip.css">
In <head>. Then write <body dark>, card, button…

exurajs

  src="https://cdn.jsdelivr.net/gh/devneet-id/exurajs@1.1.0/dist/exura.min.js">
</script>
Before your modules, at the end of <body>.
